Privacy first

Your images never leave your device

There is no backend. The app is static files, and the segmentation model runs locally with Transformers.js. There is no analytics either.

The only network request after loading is the one-time download of the model files, which your browser then caches.

✓ What stays local

Your photos, the masks, and the exported PNGs.

↓ What is downloaded

App files from the host, and the BRIA RMBG-1.4 model from Hugging Face on first use.

How it works

Four steps, all in the browser

  1. DropDrag, paste or pick one or more images.
  2. SegmentA copy (max 1024 px) goes through RMBG-1.4 with Transformers.js, on WebGPU.
  3. ApplyThe mask is resized to the original size and becomes the alpha channel.
  4. ExportDownload a PNG, copy it, or get a ZIP of the batch.

Good to know

Honest limits

First run is slower

The model has to be downloaded once. Later runs use the browser cache.

WebGPU recommended

It gives the best speed. Browsers without it may be slow or fail. This fallback is not tested.

Fine detail

The model sees at most 1024 px, so hair and similar details are limited.

Model license: the code is MIT, but the BRIA RMBG-1.4 model has its own license terms that may restrict commercial use. Read the model card first.
